# Internal usability pilot — November 2026

**Status: protocol frozen, sessions in progress.**

This is an **internal usability pilot** with 6-8 colleagues and mentors. It is not a citizen
pilot, not a representative survey, and not an external validation of the models. The goal is
to find usability and trust failures in the flagship journey before the evaluation demo.

## Method

- Protocol and consent: [`docs/pilot/README.md`](../../docs/pilot/README.md).
- Per-participant form: [`docs/pilot/session-template.md`](../../docs/pilot/session-template.md).
- Environment pre-warmed with `infrastructure/deployment/smoke.ps1` before each session.
- Think-aloud, no interface explanation before the first attempt, 2-minute blocking rule.

## How results will be used

1. Every friction point becomes a GitHub issue with the verbatim quote and a proposed fix.
2. Fixes that touch the flagship journey are re-tested in a second pass (same participants
   where possible).
3. The final report keeps the honest sample description and does not generalise beyond it.
